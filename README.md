# Transportes MORVAC — Landing page

Sitio de una página para Transportes MORVAC, empresa dedicada al transporte de carga. La landing presenta la propuesta de valor de la empresa, sus servicios, la cobertura regional y la información corporativa en una experiencia responsiva y de carga rápida.

Está construido con React 18, Vite 8 y MDB React UI Kit 8, e incluye pruebas con Vitest. El build de producción se publica en GitHub Pages.

## Desarrollo

```bash
npm install
npm run dev
```

La app se sirve en `http://localhost:5173/landing-page-transports/`.

## Scripts

- `npm run dev` / `npm start`: servidor de desarrollo.
- `npm run build`: build de producción en `dist/`.
- `npm run preview`: previsualiza el build.
- `npm test`: tests con Vitest.
- `npm run test:watch`: tests en modo watch.
- `npm run deploy`: publica `dist/` en GitHub Pages.
